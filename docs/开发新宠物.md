# 开发新宠物指南（角色内容集中化）

本项目的设计：**`src/` 核心代码与角色无关，`character/` 是角色的全部专属内容**。
开发一个新设定/新形象的桌面宠物（例如高中生 AI 助教）= 复制项目 + 改 `character/` + 改提示词，核心代码零改动。

## 目录结构

```
Desktop_Pet/
├── src/              核心源码（main/pet/chat/tts/asr/voice/…）—— 与角色无关，不要放角色信息
├── character/        角色专属内容集中地（换皮只动这里）
│   ├── config.json   名字/唤醒词/同音容错/人设/音色/课堂开关（不含明文 Key 的分发包版）
│   ├── config.example.json  配置模板
│   ├── img/          三帧形象（微笑/眨眼/说话 → prepare_avatar.py 处理成 avatar_*.png）
│   ├── fx/           音效（click/send/wake.wav，gen_fx.py 生成）
│   └── assets/       exe 图标（小云宝.ico，make_icon.py 生成）
├── scripts/          开发工具脚本（素材处理/音效/图标/诊断）
├── docs/             文档
└── dist/ build/      打包产物
```

## 开发新宠物的步骤

1. **复制整个项目文件夹**，改名（如 `Desktop_Teacher`）
2. **改 `character/config.json`**：
   - `pet.name`（新名字）、`wake_word`（唤醒词）、`wake_aliases`（同音容错表，按需）
   - `pet.persona`（新人设，一句概括身份与听众）
   - `tts.voice`（新音色）
3. **改提示词**：`src/chat.py` 的 `ChatBot._system_prompt()` 里第 1~10 条说话要求
   （自称规则、称呼规则、句长、介绍模板等）按新角色调整
4. **换形象**：把新角色的三帧图放 `character/img/`（微笑.png/眨眼.png/说话.png，
   白底、同一张基准图生成），运行 `python scripts/prepare_avatar.py` → 生成
   `character/img/avatar_*.png`
5. **换图标**：`python scripts/make_icon.py` → `character/assets/新名.ico`
6. **换音效（可选）**：改 `scripts/gen_fx.py` 的频率参数重新生成
7. **重新打包**（把命令里的名字和图标路径换成新的）：
   ```
   pyinstaller --noconfirm --noconsole --onedir --name 新名字 \
     --icon "character/assets/新名.ico" \
     --add-data "character/img;img" --add-data "character/fx;fx" \
     --exclude-module PyQt5 --exclude-module PyQt6 --exclude-module tkinter src/main.py
   ```
8. **改界面文案（可选）**：气泡占位符"和小云宝说点什么…"（src/bubble.py）、
   舞台标题"X课堂"（src/stage.py）、提示语"我在听"（src/voice.py）等

## 注意

- `config.json` 在 CWD（exe 旁）优先于 `character/`——开发时两者都要改
- API Key：开发时明文放 `character/config.json`；分发用 `scripts/make_keys.py`
  生成加密 `keys.dat`（详见 制作分发包.bat）
- 角色相关信息**不要写进 src/**（聊天护栏、安全规则这类通用规则除外）
