【在新电脑上恢复历史对话的方法】

本文件夹保存了两次开发的完整会话记录：
  会话-2026-09-30-小云宝开发.jsonl   （旧电脑 → 第一台新电脑，v1.3 时期）
  会话-2026-10-07-小云宝开发.jsonl   （第一台新电脑 → 下一台电脑，v1.5 时期，含点位授权/节能唤醒等全部开发）

恢复步骤：
1. 新电脑安装 Claude Code（claude.ai/code 下载），登录同一个账号
2. 把整个 Desktop_Pet 项目文件夹拷到新电脑任意路径（无需与原路径相同）
3. 在新电脑上用 Claude Code 打开一次该项目（会自动创建会话目录）
4. 找到对应的会话文件夹：
   C:\Users\<你的用户名>\.claude\projects\<项目路径编码>\
   （命名规则：路径里的盘符去掉、反斜杠换成-，如
    D:\Desktop\Desktop_Pet → D--Desktop-Desktop-Pet）
5. 把上面的 .jsonl 文件复制进那个文件夹
6. 在项目目录里启动 claude，输入 /resume，列表里选择对应对话 → 恢复

注意：
- 对话很长，恢复后较早内容可能被自动摘要，不影响继续开发
- 项目根目录的 CLAUDE.md 才是完整交接文档（新 Claude 会自动加载），
  即使不恢复对话也能无缝接手——里面包含所有关键决策、踩坑和常用命令
- character/config.json 里含明文 API Key，随项目文件夹拷贝时注意保密
